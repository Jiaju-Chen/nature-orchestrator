# Vision

NatureOrchestrator is a method project, not just a benchmark entry. The long
term goal is to help researchers write stronger papers from their own research
materials.

The benchmark setting starts from public Nature artifacts because it gives a
strict test bed: code, source data, figures, supplementary materials, and a
published manuscript for oracle audit. Real usage can start from unpublished
experiments, private notebooks, draft figures, rough ideas, lab notes, and
coauthor feedback.

## Design Principles

- Evidence before prose.
- Figure-driven results writing.
- Explicit separation between generation context and oracle review context.
- Section-level mask, rewrite, and critique loops.
- Structured artifacts that can be reused by Codex, Claude Code, and other
  agent runtimes.
- No data-figure generation from image models; scientific figures must be
  produced from data and code.
