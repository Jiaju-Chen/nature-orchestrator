# Write, Review And Refine Method

Use this method for every section and for final full-paper polish.

## Loop

```text
plan
-> write
-> deterministic gates
-> reviewer
-> refine if needed
-> reviewer again
-> pass, fail, or stop at budget
```

## Writer

The writer drafts from allowed evidence and the current story plan. It may
improve order, emphasis, paragraph flow and venue style. It must not add new
findings, unsupported numbers, hidden citations or oracle details.

## Reviewer

The reviewer is section-specific. It must identify concrete missing anchors,
direction or comparator errors, overclaims, unsupported implications, generic
story framing and section-role failures. It must not pass a draft only because
the prose is fluent.

## Refiner

The refiner revises only blocking issues, required revisions and deterministic
gate failures. It should preserve supported anchors and avoid broad rewrites
unless the reviewer says the story route itself is wrong.

## Stop Rule

Stop when the reviewer passes, the output fails unrecoverably, or the maximum
refinement budget is exhausted. If budget is exhausted and the section still
needs revision, record that explicitly.
