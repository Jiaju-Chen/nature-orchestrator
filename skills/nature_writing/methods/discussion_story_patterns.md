# Discussion Story Patterns

Use these as generic Discussion-planning rules, not as facts about the current
paper.

- Start from what the Results change, not from a generic field recap.
- Synthesize across evidence roles instead of repeating figure order.
- Put limitations near the claims they qualify.
- Explain why the interpretation is credible before broadening implications.
- Use weak, null, subgroup, proxy or model-dependent evidence as boundary
  language.
- Preserve key values, methods or comparator anchors only when needed for the
  interpretation.
- End with a paper-specific implication, transfer condition, next question or
  conceptual payoff.
