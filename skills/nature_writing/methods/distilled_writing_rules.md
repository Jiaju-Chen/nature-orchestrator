# Distilled Writing Rules

These rules are safe generalizations for evidence-grounded scientific writing.

- A polished but generic section should not pass review.
- A plan anchor is not recalled unless it appears in the final text.
- Exact values outside Results require matching Results support.
- Strong causal language requires experimental, mechanistic or design support.
- Methods details matter when they explain access, validity, control, workload,
  scale, transfer or claim boundaries.
- Conservative writing can still fail if it erases the paper's recoverable
  contribution.
